# Content to send

Everything on the site is data. Send any of this and it goes straight into place.

**Per project**: use `docs/PROJECT_TEMPLATE.md` (brief, features, team, mentor, timeline, GitHub repo, demo link).

**Certifications** (`src/data/certifications.ts`): title, issuer, date, skills, credential ID, verify link. Add PDFs/images if you want them shown.

**Achievements** (`src/data/achievements.ts`): title, issuer, date, one-line description (patent, hackathons, awards).

**Experience / leadership** (`src/data/experience.ts`): role, organisation, period, 2-3 bullet points.

**About** (`src/data/about.ts`): bio edits, stats, skills and levels.

**Cabin**: a photo or 3D model of you to replace the stand-in figure (`src/features/city/cabin/Avatar.tsx`).
